# CodeCelix Portfolio

CodeCelix Portfolio is a responsive company portfolio website built to showcase the services, projects, and technical work of CodeCelix. The website highlights web development projects, AI and automation solutions, UI/UX designs, and interactive demo presentations in a clean and professional layout.

## About the project

This portfolio was created to present the work of CodeCelix in a simple and visually engaging way. It includes project thumbnails, demo videos, company branding, and dedicated sections for different areas of expertise.

The website is fully responsive and works across desktop, tablet, and mobile devices.

## Features

* Responsive design for all screen sizes
* Modern and clean user interface
* Project showcase section with thumbnails and demo videos
* Dedicated sections for web development, AI solutions, app development, and UI/UX design
* Smooth navigation and interactive elements
* Lightweight static website built with HTML, CSS, and JavaScript

## Technologies used

* HTML5
* CSS3
* JavaScript

## Running the project locally

Clone the repository:

```bash
git clone https://github.com/Kiran-Ghafoor/CodeCelix-Portfolio.git
```

Open the project folder and run `index.html` directly in your browser, or use the **Live Server** extension in VS Code for a better development experience.

## Deployment

The project is deployed on **Vercel** and can be accessed through the live deployment link after deployment is completed.
